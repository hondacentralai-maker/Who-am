# خطة التنفيذ المفصلة: المرحلة الثالثة (Phase 3 Implementation Plan)

## 1. الشرائح الرأسية للتنفيذ (Vertical Slices)

### الشريحة 3.1: دعم بث أنماط الألعاب في `SupabaseService`
- إضافة دالة `sendGameModeChange` لبث النمط المختار (`cards`, `knowMe`, `guessWho`).
- إضافة دالة `sendKnowMeEvent` لبث أحداث «قد إيش تعرفني؟».
- إضافة دالة `sendGuessWhoEvent` لبث أحداث «خمن الشخصية».
- إضافة كولباكات الاستماع المقابلة في `subscribeToRoomWithPresence`.

### الشريحة 3.2: بناء مبدل الأنماط في `ActiveOnlineRoomScreen`
- تعريف تعداد `OnlineGameMode { cards, knowMe, guessWho }`.
- تصميم شريط تبديل علوي متناسق ومستجيب (Segmented Switcher).
- تبديل العرض بين الأنماط عند النقر أو عند استلام حدث البث.

### الشريحة 3.3: مكون اللعب عن بعد لـ «قد إيش تعرفني؟» (`OnlineKnowMeView`)
- واجهة أنيقة متكاملة مدمجة داخل الغرفة:
  - عرض السؤال الحالي.
  - إدخال الإجابة السرية لمن عليه الدور مع مؤشر انتظار للشريك.
  - إدخال التخمين عند جاهزية الإجابة السرية.
  - الكشف المتزامن واحتساب النقاط واختيار السؤال التالي.
- دعم كامل للتغذية اللمسية وإمكانية إرسال التفاعلات في أي لحظة.

### الشريحة 3.4: مكون اللعب عن بعد لـ «خمن الشخصية» (`OnlineGuessWhoView`)
- واجهة تفاعلية ذكية:
  - اختيار الشخصية السرية لكل لاعب مع إشارة جاهزية الطرفين.
  - شبكة الشخصيات الـ24 مع ميزة النقر للاستبعاد الفوري محلياً.
  - شريط حوار لطرح أسئلة سريعة حول الصفات والإجابة بنعم/لا.
  - نافذة التخمين النهائي للتحقق من هوية الشخصية السرية والاحتفال بالفائز.

### الشريحة 3.5: الاختبارات والتدقيق الشامل
- كتابة اختبارات وحدة وواجهات في `test/widget_test.dart` تغطي كافة الأنماط والرسائل.
- تشغيل `flutter analyze` و `flutter test`.

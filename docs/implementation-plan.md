# خطة التنفيذ المفصلة: المرحلة الثالثة (Phase 3 Implementation Plan)

## 1. الشرائح الرأسية للتنفيذ (Vertical Slices)

### الشريحة 3.1: دعم بث أنماط الألعاب في `SupabaseService`
- إضافة دالة `sendGameModeChange` لبث النمط المختار (`cards`, `knowMe`, `guessWho`).
- إضافة دالة `sendKnowMeEvent` لبث أحداث «قد إيش تعرفني؟».
- إضافة دالة `sendGuessWhoEvent` لبث أحداث «خمن الشخصية».
- إضافة كولباكات الاستماع المقابلة في `subscribeToRoomWithPresence`.

### الشريحة 3.2: بناء مبدل الأنماط في `ActiveOnlineRoomScreen`
- تعريف تعداد `OnlineGameMode { cards, knowMe, guessWho }`.
- تصميم شريط تبديل علوي متناسق ومستجيب (Segmented Switcher).
- تبديل العرض بين الأنماط عند النقر أو عند استلام حدث البث.

### الشريحة 3.3: مكون اللعب عن بعد لـ «قد إيش تعرفني؟» (`OnlineKnowMeView`)
- واجهة أنيقة متكاملة مدمجة داخل الغرفة:
  - عرض السؤال الحالي.
  - إدخال الإجابة السرية لمن عليه الدور مع مؤشر انتظار للشريك.
  - إدخال التخمين عند جاهزية الإجابة السرية.
  - الكشف المتزامن واحتساب النقاط واختيار السؤال التالي.
- دعم كامل للتغذية اللمسية وإمكانية إرسال التفاعلات في أي لحظة.

### الشريحة 3.4: مكون اللعب عن بعد لـ «خمن الشخصية» (`OnlineGuessWhoView`)
- واجهة تفاعلية ذكية:
  - اختيار الشخصية السرية لكل لاعب مع إشارة جاهزية الطرفين.
  - شبكة الشخصيات الـ24 مع ميزة النقر للاستبعاد الفوري محلياً.
  - شريط حوار لطرح أسئلة سريعة حول الصفات والإجابة بنعم/لا.
  - نافذة التخمين النهائي للتحقق من هوية الشخصية السرية والاحتفال بالفائز.

### الشريحة 3.5: الاختبارات والتدقيق الشامل
- كتابة اختبارات وحدة وواجهات في `test/widget_test.dart` تغطي كافة الأنماط والرسائل.
- تشغيل `flutter analyze` و `flutter test`.

## 2. الشرائح الرأسية للمرحلة الرابعة (Phase 4: Lifestyle & Partner Invitations)

### الشريحة 4.1: نماذج البيانات وخدمة التخزين المحلي
- بناء نموذج `CouplesProfile` لحفظ أسماء الشريكين، تاريخ الارتباط، كود الشريك، وحساب أيام الحب والذكرى السنوية.
- بناء نموذج `LoveNote` للرسائل الرومانسية والكبسولات المقفلة زمنياً.
- بناء نموذج `DecisionWheelItem` للتصنيفات الافتراضية والمخصصة لعجلة الحظ.
- تحديث `PreferencesService` بدوال CRUD الكاملة للملف المشترك والرسائل والخيارات.

### الشريحة 4.2: نظام ربط الشريك الدائم والدعوات المباشرة (1-Click Partner Invites)
- إضافة قنوات البث الفوري للدعوات الشخصية في `SupabaseService.subscribeToUserInvites` و `sendPartnerInvite`.
- بناء نافذة `PartnerLinkDialog` لربط الشريك بواسطة الكود أو البريد الإلكتروني مع إمكانية إلغاء الارتباط.
- إضافة زر الإرسال المباشر للدعوة في `OnlineRoomScreen` و `ActiveOnlineRoomScreen`.
- استماع الشاشة الرئيسية `HomeScreen` للدعوات الواردة وعرض نافذة منبثقة تفاعلية تأخذ الشريك مباشرة للغرفة دون كتابة أي رمز.

### الشريحة 4.3: شاشة عجلة القرارات اللطيفة للأزواج (`DecisionWheelScreen`)
- رسم العجلة الدوارة بنظام `CustomPainter` بفيزياء دوران تباطؤية وتغذية لمسية عند كل قطاع.
- تصنيفات مسبقة («عشاء الليلة؟»، «سهرة الليلة؟»، «تحدي الدلع») وإمكانية إضافة خيارات جديدة.
- نافذة الاحتفال بالخيار الفائز.

### الشريحة 4.4: كبسولة رسائل الحب والذكريات (`LoveNotesScreen`)
- تصنيف الرسائل حسب الحالة (مفتوحة / كبسولات مؤجلة).
- حماية الكبسولات بعد تنازلي يمنع فتحها حتى يحل التاريخ المستهدف.
- تجربة قراءة تفاعلية مع أنيميشن وزر مشاركة.

### الشريحة 4.5: بطاقة مشاركة اللحظات (`ShareMomentsDialog`) وبانر الشريكين
- بناء بانر رومانسي جذاب `CouplesDaysBanner` في أعلى الشاشة الرئيسية يعرض أيام الحب والعد التنازلي للمناسبات.
- نافذة تصدير بطاقة المشاركة لواتساب مع إحصائيات السلسلة والنقاط وأيام الارتباط.

# خطة الاختبارات والتحقق للمرحلة الثالثة (Phase 3 Test Plan)

## 1. الأهداف
التحقق من صحة واستقرار الأنماط الثلاثة وتكامل البث الفوري والتغذية اللمسية بدون اتصال خارجي أو عند انقطاع الاتصال.

## 2. مصفوفة حالات الاختبار (Test Matrix)

| رقم | نطاق الاختبار | النتيجة المتوقعة |
|---|---|---|
| TC-01 | تعداد `OnlineGameMode` وتحويل السلاسل | التحقق من صحة التحويل من وإلى النص للأنماط الثلاثة |
| TC-02 | بث تبديل النمط | التحقق من صحة توليد واستقبال رسالة `game_mode_change` |
| TC-03 | سير لعبة «قد إيش تعرفني؟» | التحقق من خطوات الإجابة السرية، التخمين، الكشف المتزامن، واحتساب النقاط |
| TC-04 | سير لعبة «خمن الشخصية» | التحقق من جاهزية اختيار الشخصية، استبعاد البطاقات، والتخمين النهائي |
| TC-05 | تبديل الأنماط في واجهة الغرفة | التحقق من عرض المبدل والتبديل بين بطاقات الحوار، قد إيش تعرفني، وخمن الشخصية |
| TC-06 | سلامة التحليل الساكن | صفر أخطاء أو تحذيرات في `flutter analyze` |
| TC-07 | نجاح مجموعة الاختبارات | نجاح كافة الاختبارات بنسبة 100% في `flutter test` |
